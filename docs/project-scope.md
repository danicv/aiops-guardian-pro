# Project scope

## Product
AIOps Guardian Pro — Agentic DevOps, Release & Reliability Intelligence Platform

## Use cases

### Pipeline intelligence
Diagnose failed CI/CD runs, retrieve failed stages/logs/tests/IaC results, compare against previous successful runs and recommend fixes.

### Release intelligence
Analyze code/config/resource changes, calculate release risk and gate production promotion.

### Runtime AIOps
Investigate Kubernetes incidents, correlate telemetry and changes, retrieve runbooks/history, and produce evidence-backed RCA.

### Governed remediation
Recommend actions, apply deterministic policy, obtain human approval, execute controlled remediation and verify recovery.

### Continuous learning
Store incident/release/approval/remediation outcomes and use them to improve future release decisions.
